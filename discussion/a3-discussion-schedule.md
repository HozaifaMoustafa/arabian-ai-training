# A3 Discussion Schedule — Full Round

Only 5 groups on-site, so no rotation is needed — every group presents live each project cycle.

## How it works

- The meeting a project's deadline falls before is that project's discussion round.
- **"S" numbers are curriculum sessions, not meetings.** A session can run across two meetings, or share one with a discussion round. Everything below is keyed on dates.
- All 5 groups present in order (`a3-g01` → `a3-g05`), ~7–8 minutes each including Q&A, to fit a single meeting.
- No written recap needed — everyone gets a live slot every time.
