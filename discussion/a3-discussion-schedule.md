# A3 Discussion Schedule — Full Round

Only 5 groups on-site, so no rotation is needed — every group presents live each project cycle.

## How it works

- After each project's due date, the following on-site session is the discussion session.
- All 5 groups present in order (a3-g01 → a3-g05), ~7–8 minutes each including Q&A, to fit a single session.
- No written recap needed — everyone gets a live slot every time.
