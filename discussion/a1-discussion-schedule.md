# A1 Discussion Schedule — Rotating Spotlight

With 15 groups meeting Mon/Thu, not every group can present live each session. Discussions run on a rotation so every group gets a live spotlight slot once per project cycle, and no session runs long.

## How it works

- **Spotlight groups per session:** 3–4 groups present live (5 min presentation + 2 min Q&A each), picked in order from the group queue below.
- **Everyone else:** groups not spotlighted that session post a short written recap (4–6 sentences: what you built, your key decision/result, one open question) inside their own submission folder, e.g. `submissions/a1-mon-thu/a1-g07/01-ml-project/a1-g07_recap.md`. The instructor reviews these async.
- **Rotation rule:** the queue continues where it left off — after `a1-g15` presents, the next project starts again from `a1-g01`. A full rotation takes 4 sessions (2 weeks), which is one project cycle.
- **Project due-date sessions:** the discussion block for a project starts at the session its deadline falls before.
