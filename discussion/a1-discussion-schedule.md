# A1 Discussion Schedule — Rotating Spotlight

With ~15 groups meeting Mon/Thu, not every group can present live each session. Discussions run on a rotation so every group gets a live spotlight slot roughly once per project cycle, and no session runs long.

## How it works

- **Spotlight groups per session:** 3–4 groups present live (5 min presentation + 2 min Q&A each), picked in order from the group queue below.
- **Everyone else:** groups not spotlighted that session post a short written recap (4–6 sentences: what you built, your key decision/result, one open question) inside their own submission folder, e.g. `submissions/a1-mon-thu/a1-g07/01-ml-project/a1-g07_recap.md`. You review these async.
- **Rotation rule:** the queue simply continues where it left off — after `a1-g15` presents, the next session starts again from `a1-g01`. This guarantees a full rotation roughly every 4 sessions (2 weeks), and repeats across every project so it's not always the same groups presenting first.
- **Project due-date sessions:** the class session immediately after a project's due date is the discussion session for that project — spotlight groups present that project's results.
